# Agent specifications

The package provides O0 and thirteen specialist profiles, common instructions, illustrative orchestration and connector configuration, initial task specifications, and report/finding templates. All roles are on demand. No model, provider account, native coordinator, daemon or autonomous executor is included.

Load [COMMON.md](COMMON.md), then the assigned [profile](profiles/O0.md). Use the existing deployment coordinator for task ownership, authorization, budgets, revocation and designated writers. A profile never grants access to a website or a right to publish.

| ID | Responsibility |
|---|---|
| O0 | Orchestration, priorities, conflicts and consolidated evidence |
| S1 | Inventory and evidence |
| S2 | Technical SEO and migration |
| S3 | Demand and keywords |
| S4 | Content, AEO and entities |
| S5 | Localization and territory |
| S6 | Structured data and feeds |
| S7 | GEO and answer evaluation |
| S8 | Media, performance and experience |
| S9 | Authority and distribution |
| S10 | Measurement and experimentation |
| S11 | Security, privacy and policy |
| S12 | Independent qualification |
| S13 | Documentation and learning |

`orchestration.example.json` is deliberately read/propose-only. Its model bindings are unresolved deployment choices. `connectors.example.json` contains unqualified declarations, not implemented integrations or authenticated sessions. `initial-work.example.json` contains proposed tasks, not executed task receipts.

The [local inspector](../tools/observer/README.md) validates this package's configuration and optional file hashes. It performs no crawl, index inspection, model call, external notification or product write. The original deployment-specific queue, scheduler receipts, local state and operational source manifest are excluded from this export.
