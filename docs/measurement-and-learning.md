# Measurement and Controlled Learning

## Baseline and objectives

Each project chooses eligible acquisition pages, target markets/locales, priority intents, business outcomes and affordable observation interfaces. Save a dated baseline before changing assets. Distinguish source acceptance, integrated code, deployed HTML, search-index observation and eventual outcomes.

| Metric | Definition and denominator | Interpretation limit |
|---|---|---|
| Organic top-five coverage | Observed eligible query/context cells in positions 1–5 divided by all successfully observed eligible cells | Publish unknown-cell coverage separately; fixed engine/country/device/time/depth |
| Search clicks/impressions | First-party reported values for exact filters, period and data state | Partial/withheld/top-row exports are not complete populations |
| Answer mention rate | Successful answer trials containing the entity divided by successful eligible trials | API and consumer interface are different cohorts |
| Correct citation rate | Successful eligible trials with a relevant, factually supporting citation divided by eligible successful trials | Citation order is not organic rank; mention need not be citation |
| Recommendation rate | Eligible successful trials recommending the offer divided by eligible successful trials | Record intent/eligibility criteria and whether ordered lists were actually produced |
| Qualified conversion | Agreed completed outcome divided by the agreed attributable opportunity set | Click, reservation, paid transaction and delivered service are different events |
| Net outcome | Approved aggregate value after cancellations/refunds/cost | No personal/clinical joins by default |
| Operational efficiency | Cost and reviewer time per useful resolved task | Include failed/rejected/no-change attempts and unknown cost |

For every rate report numerator, denominator, successful coverage, failed/unknown/withheld count and confidence limitations. Do not hide an outage by dropping difficult cells. GSC average position is not a fixed keyword rank; a model API answer is not proof of placement in a consumer app.

## Experiment definition

Before the intervention record hypothesis, target/control or comparison, baseline, evaluation window, primary metric, practical minimum effect, safety/UX guardrails, stopping rule, expected data lag and confounders. Use randomized or controlled comparisons when practical; otherwise label before/after results as observational.

Allow a reasonable crawl/index/outcome window for the actual surface rather than rewriting daily. Record competing releases, price/capacity changes, seasonality, algorithm changes and sampling changes. A result may be negative or inconclusive. Do not change the fixed panel or thresholds after seeing results without registering a new experiment.

## Method and adapter promotion

S13 links outcomes and new primary-source guidance to a versioned rule proposal. S12 evaluates it against known regressions and held-out tasks: truthfulness, unknown-state handling, scope preservation, useful diagnosis, safety, cost, latency and human review burden. Clinical validation remains with competent humans.

Compare against the current method and a simpler analyst baseline. Extra specialists or external reviewers are added when they improve accuracy, isolation or total cost; model count is not a quality metric. Preserve negative and dissenting results. A method update cannot increase permissions, reset budgets or alter evaluation denominators in the same promotion.
