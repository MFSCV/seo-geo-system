## Interpretation limits

- No target repository or private history was audited for this research. No source, prompt, corpus or asset was declared cleared for redistribution.
- The Apache-2.0 recommendation is a design choice based on the primary license wording. It does not select an owner, grant rights or replace approval by the actual rights holders.
- SPDX/REUSE metadata helps make licensing explicit; it does not prove authorship, permission, license compatibility or privacy clearance.
- Platform availability and UI wording can change. Recheck the linked official pages at implementation/publication time, especially Actions lockfile availability and release/security features.
- GitHub's SBOM REST API currently documents migration to asynchronous request/fetch generation before a synchronous endpoint shutdown on 2026-11-13. The plan intentionally avoids prescribing that soon-obsolete endpoint. See [SBOM REST API](https://docs.github.com/en/rest/dependency-graph/sboms), retrieved 2026-11-02.
- The MCP link above is the official redirected destination reached from `https://modelcontextprotocol.io/specification/2026-07-28/basic/security_best_practices`. No MCP runtime or conformance is asserted.
