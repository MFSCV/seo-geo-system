# Measurement and experiments

## Preserve metric meaning

| Source | Useful signal | Limit |
|---|---|---|
| GSC Search Analytics | Clicks, impressions, CTR, average position by available dimensions | Top rows/omitted queries; average position is not one fixed rank |
| GSC URL Inspection | Known indexed version, canonical/crawl fields returned | No live test or indexing request through that API |
| GSC Generative AI report | Impressions in AI Overviews/AI Mode; page/country/date/device and text/multimodal where available | Dated docs do not promise clicks, position or prompts in that report; data also belongs to overall Web |
| Bing AI Performance | Citations, pages, grounding samples and available topics/intents/share | Citation/Share is not click, conversion, importance or universal ranking |
| Approved analytics/referral | Observed entrances and aggregate funnel | Attribution loss; no-referrer is not no influence |
| Approved operational aggregate | Booking/payment/completion/cancellation distinctions | A click is not a confirmed booking/payment or clinical outcome |
| Field/lab performance | Experience signals and cause diagnosis | Missing field sample is unknown; lab does not substitute field |
| Synthetic AI question panel | Observed mention/citation/accuracy | Not a population estimate or universal LLM rank |

Register property, source/API/UI, period/cutoff, original timezone, filters/dimensions, lag/preliminary status, coverage, aggregation and supplier/version. Keep real zero, missing/censored values and failure distinct; exports can turn unavailable markers into zeros. Compare matching windows and contexts, not incompatible dashboard totals.

Dated snapshot 2026-11-02: dedicated GSC generative reports/control are documented globally since 2026-08-31. Missing report may reflect insufficient impressions or inclusion setting. Do not repeat old Web-only claims. Qualify real UI access and export/API separately; never invent an API because a UI report exists.

Use current API quotas and pagination, not maxima as consumption targets. URL Inspection is not the Google Indexing API. The latter is restricted to eligible jobs/livestreams, not ordinary service pages. IndexNow receipt is not indexing and does not imply Google participation.

## AI sampling

Reuse a fixed versioned panel initially comprising 24 public PT/EN questions: eight service-intent, eight informational, eight brand/factual. Refine representativeness without replacing the comparison set silently. Keep exploratory additions separate and never use real patient cases.

Record question ID/text/version, language/market/context, time, product/model when exposed, search enabled/unknown, session/personalization limits, response, cited URLs, brand mention, recommendation, price/terms and error severity. A failed execution is not a missing citation. Separate clickable citation, unlinked mention, recommendation and factual correctness.

Choose accessible permitted interfaces first. API answers may not match the consumer product. Additional repeats per question, surfaces and monthly cadence are a sampling proposal bounded by budget, not a compulsory purchase or automatic schedule. No complete owner dashboard for all ChatGPT/Claude citations is established by this skill.

For Perplexity identify its actual search crawler vs user retrieval from current primary docs and qualify the chosen interface. For Grok distinguish public web search, X/social search and product-specific outputs; discovering an API capability is not inclusion in organic search or authority to post. Do not invent a deployment-specific X account. Do not assume one universal crawler policy for all providers.

Referrer/UTM detection uses actual received data, not an exclusive hardcoded ChatGPT UTM requirement. Check accuracy as well as visibility: a cited but false service description is not success.

## Experiments

Stabilize factual/technical integrity and eligibility first. Pre-register hypothesis, pages/group, comparable control when meaningful, intervention, primary metric/guardrails, baseline, minimum useful effect, window/stopping rule, costs and confounders.

Suggested starting parameters: comparable 28-day baseline, 28–56-day editorial window adjusted to crawl/sample, one experiment per group and at most one initial editorial batch weekly. These are tunable operating proposals, not engine rules. Immediate factual/privacy/booking/5xx incidents do not wait for the window.

Record seasonality, campaigns, capacity/pricing, other releases, engine/model changes and data changes. Use staged/comparable analysis where useful. Before/after alone is association. Classify gain/regression/inconclusive/observation and preserve negative results. No forced winning conclusion from a small sample.

Measure useful acquisition against actual capacity and validated contribution margin, not consultation price as margin. Separate incremental software, human review, existing contracts, cancellations/refunds and initial payback. Fix goals only after a homogeneous baseline; do not promise permanent top-five placement.

## Pilot acceptance

For the prioritized IMT PT/EN + legacy lot: every URL observed or unknown explained; P0 findings reviewed with reproducible evidence; no known P0 false positive after review; no critical privacy/booking/intentional-indexing regression in candidates; cost/duration measured; conclusions explicitly classified. A tiny zero-false-positive sample is not universal accuracy proof.
